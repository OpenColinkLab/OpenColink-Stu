# v0.1.0

首次发布 Apple Silicon macOS 运行包。

- 本地网页界面：查询音质、选择 AAC / ALAC / Hi-Res / Dolby Atmos 下载，查看日志、停止任务和设置下载目录。
- 提供登录、后端服务、命令行下载和图形界面启动脚本。
- 附带 amdl v0.1.0、wrapper-lite 启动器和所需 Linux 运行文件。
- 使用全新空白磁盘模板，首次运行生成个人配置和登录磁盘。

要求：Apple Silicon Mac，已安装 Python 3、QEMU、ffmpeg。安装方法见 README。

附件：`applemusicdownloader-v0.1.0-macos-arm64.tar.gz`、`SHA256SUMS.txt`。
