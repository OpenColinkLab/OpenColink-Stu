# 奶蛙博物馆 · 免登录 HTML

最终文件为工作区根目录的 `奶蛙博物馆.html`，约 5 MB。打开该文件即可使用，不需要安装依赖或启动服务。

- 主馆保留 149 件作品、两馆分类分页、作品详情、翻面与原作图、艺术家、鉴定、档案、日志、主题、双语和背景音乐。
- 五个分馆的程序内嵌在同一 HTML 中：3D展馆、小镇、尖塔、制造所、幸存者。通过主馆分馆入口进入、顶部按钮返回。
- 身份、收藏、喜欢、留言、头像和工坊结果仅存在本机浏览器；不需要 Neta/Studio/Cohub 账号，不会上传参考图或写入原站。
- 意见箱导出本地 JSON，头像可导出 PNG，表情可打包 ZIP；支持本地摇摆动画与 GIF 编码。
- 制造所原站的付费 AI 生成被改为明确标注的本地画布合成预览，无法代替真实 AI 重绘；没有收费或模型调用。
- 页面与六个应用的脚本、样式、依赖均已内嵌。大部分图片、字体、视频和音频仍使用原公开资源地址，因此加载媒体需要联网；这不是全部媒体离线归档。

验证包含主馆桌面功能、手机菜单/翻面/分页、五馆切换及内部核心功能、免登录收藏评论、PNG/意见导出事件、制造所合成与视频/GIF。所有验证均未发现页面 JavaScript 错误、账号请求或对外 POST。取证工具会取消真实文件下载，但已捕获 PNG/JSON 的本地 Blob 下载事件。未穷举所有游戏内容，也没有把服务器预览当作对全部浏览器文件协议行为的保证。
