# 奶蛙博物馆：完整版离线 HTML

交付文件：项目根目录的 `奶蛙博物馆-完整版离线.html`。

将这个 HTML 复制到其他设备，用支持 JavaScript、WebGL 和音视频解码的现代浏览器打开即可。无需服务器、登录、网络或配套资源文件。约 582 MB，首次加载和图片解码需要时间及足够内存；未验证的老旧设备和浏览器不保证兼容。

包含主馆的西方馆、中国馆、形象档案、鉴定、收藏和本机留言，以及 3D 展馆、奶蛙小镇、奶蛙尖塔、奶蛙制造所、奶龙幸存者五个分馆。855 个公开媒体与字体地址对应的内容完整收录，按内容去重后内嵌 852 份资源；另有原游戏内置的素材和本地代码。PNG 转为无损 WebP，逐像素校验，保留尺寸和透明度。音视频保留原文件。

收藏、留言、身份和存档保存在浏览器本机。制造所提供本地画布合成、头像 PNG、动画 WebM 和 GIF；原站的付费云端 AI 功能仍由本地合成预览替代，不调用真实 AI 服务。

验证包括：所有缓存资源可解码；所有内嵌二进制的 SHA-256 与打包清单一致；新建 Chromium 浏览器配置、网络离线、直接 file:// 打开；桌面主馆与五个分馆；手机尺寸入口和中国馆翻页；音视频元数据解码；制造所 PNG 与 GIF 导出。文件改名并放入没有资源目录的临时目录后仍通过手机尺寸检查。

证据：`build-report.json`、`asset-validation.json`、`package-verification.json`、`qa/result.json`、`qa/mobile-result.json` 及 REA 的 `qa/*process-evidence.json`。
