# 宿舍 · 空间手记

根据 `reference/` 内四张照片综合重建的四人宿舍。无人物。Three.js + 原生 JavaScript，无后端。

## 直接打开

双击构建生成的 `宿舍3D.html`，在支持 WebGL 2 的现代浏览器中查看。此文件包含全部脚本与样式，可离线打开。

## 开发

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run build
```

`dist/` 可部署在任意静态网页服务器。构建同时生成离线单文件 `宿舍3D.html`。

## 操作

左键拖动旋转；滚轮缩放；右键拖动平移。手机单指旋转，双指缩放、平移。R 重置；F 全屏。点击自动旋转后开始缓慢展示，操作场景立即停止。

## 场景

房间尺寸按照片视觉比例估计为约 3.6 × 5.8 × 3.25 米。四组黑色铁架上床下桌、蓝灰床帐、木色桌柜、侧面入口与门上空调、两端的窗户与阳台开口、共用盆架、行李箱、电脑和纸箱。使用随视角变化的墙体剖切展示，俯视时隐藏天花板灯具，保留低视角的灯具。

参考照片不打包到网页，也不推送到托管服务。

## 开发环境与依赖恢复

在本项目目录执行开发命令。使用 Node.js 22.12+ 和 npm；保留并提交 `package-lock.json`，首次下载或同步依赖后运行 `npm ci`。不要提交 `node_modules/`。更新依赖时使用 `npm install` 并同时审阅清单和锁文件的变化。构建目录不能代替源码。
