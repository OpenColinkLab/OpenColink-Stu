# XDU 学习项目

各子目录相互独立：

- [ai-lab](ai-lab/README.md)：机器学习 Jupyter 笔记本，依赖声明见 `ai-lab/requirements.txt`。
- [homework](homework/README.md)：C/C++ 独立练习。
- [homework2](homework2/README.md)：另一组 C/C++ 独立练习，部分旧文件含非 UTF-8 中文字符串。

请先阅读对应 README。每份 C/C++ 源文件一般具有自己的 `main`，应单独编译；Python 实验在虚拟环境中安装依赖并通过 Jupyter 执行。
