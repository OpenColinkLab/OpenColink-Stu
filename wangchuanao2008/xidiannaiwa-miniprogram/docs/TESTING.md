# 验证与验收

## 可复现检查

```sh
npm run check
npm test
```

没有第三方测试依赖。覆盖清单一致性、所有作品的可达性、排序与分页边界、中英文搜索、展馆/展厅隔离、包含特殊字符的分享参数、页面筛选及防抖、详情分享和循环导航、失效 ID、图片状态、返回策略，以及 HTTP 资源服务的图片读取/HEAD/写入与路径隔离。

页面测试在 Node 中提供 Page/wx 桩，验证逻辑和导航参数，不模拟微信视图层或真实 wx API。不要将这些结果写成“真机测试通过”。

## 可选原生模板编译

如安装的微信开发者工具提供 wcc/wcsc，可运行：

```sh
WECHAT_COMPILER_DIR=/absolute/directory/containing/wcc-and-wcsc node scripts/check-wechat-compilers.mjs
```

macOS 的常见目录是 `/Applications/wechatwebdevtools.app/Contents/Resources/app.asar.unpacked/node_modules/wcc-exec`。这是可选工具路径，不是项目硬编码依赖；不同版本工具可能移动或不再提供这些二进制。它检查模板/样式语法，不代表模拟器运行和设备视觉验证。普通接手者可直接在微信开发者工具导入编译。

## 手动验收矩阵

| 场景 | 预期 |
| --- | --- |
| 首页 | 完整校名校徽、两张正确轮播、两条新闻 |
| 校徽文章 | 三段正文完整，返回首页 |
| 常设典藏 | 114 件，24 件/页，共 5 页 |
| 中国馆 | 35 件，24 件/页，共 2 页 |
| 文艺复兴/中国隋唐 | 分别 5 / 7 件 |
| 搜索“星月” | 唯一命中“星月奶蛙夜” |
| 无结果关键词 | 空态，页码 1/1，不跳出范围 |
| 作品详情 | 中文/英文标题、年代、艺术家、介绍与观展提示 |
| 高清图/弱网 | 缩略图过渡、原图加载；失败可重试；可放大 |
| 上一件/下一件 | 在筛选结果循环，末尾可回第一件 |
| 正常返回展馆 | 筛选、搜索、页码和原页面状态保留 |
| 分享作品直达 | 恢复对应 ID，下一件后分享对应当前作品 |
| 分享直达后的页内返回 | 无上级页面时能进入展馆 |
| 无效作品 ID | 友好空态，可返回展馆 |

至少检查 iOS / Android、窄屏、大字体、安全区与 HTTPS 正式网络设置。分享及真机预览依赖真实 AppID、账号权限和网络；游客模式不可代替正式验收。
