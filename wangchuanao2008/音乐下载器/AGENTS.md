# 项目约定

- 用户要求：后续开发和发布统一 macOS、Windows、Android 的版本号。
- 根目录 `VERSION` 是唯一共享版本来源。版本变更只修改此文件，让各平台构建配置、应用元数据、安装器、包名中的版本和 GitHub Release 标签保持一致；Android 的整数 versionCode 仍须递增。
- 已发布的 v1.1.0 是现有构建的汇总发布标签，各安装包内部版本尚未统一。不要只改文件名或 Release 标签，就宣称包内版本已经统一。
- 统一版本号不代表功能已对齐；发布说明须明确各平台功能差异和实际验证范围。
- macOS 与 Windows 共用根目录 `musicdown/`，不要恢复独立的 Windows 功能分支。Android 保持同一功能清单，并跑原生音频设备测试。
