# 1.2.1 更新与验证

版本以根目录 `VERSION` 为准。macOS/Windows 应用元数据、Windows EXE/安装器、Android versionName 和发布文件名均由该文件生成；Android versionCode 从 10200 升至 10201。

## 更新

- 登录直接进入网易云官方 `https://music.163.com/#/login` 登录页。Android 请求官方桌面登录路由并只调整页面布局，避免默认手机 User-Agent 被转到音乐首页；提供窄屏缩放与更大的登录窗口。二维码和安全验证仍由网易云处理。
- Android 使用系统栏、刘海、导航栏和键盘的窗口 inset 留出空间，标题不会放在状态栏区域。
- “备用音源（GD Studio）”与官方音质档位并列。选择它后直接查询对应歌曲 ID，不携带网易云账号会话；保存后显示文件检测得到的实际音质。取消旧的备用来源复选框，自动音质只回退网易云公开音源；失败时提示单独选择备用音源。
- Windows/macOS 共用根目录 `musicdown/`，Windows 启动与打包均从共享代码入口构建，删除过时的 Windows 独立实现。三端统一粘贴后先解析、选择档位、点击下载确认的流程，并支持批量下载、取消/重试、会话保存、MP3 转换、元数据和封面。
- Android 内置 FFmpeg/FFprobe，与桌面音频检测及处理功能对应；桌面仍需要外置工具。

## 平台差异与限制

三端实现同一功能清单，不代表运行结果已在三端验收。macOS 会话存于钥匙串，Windows 存于凭据管理器，Android 存于 Keystore 加密存储。桌面需外置 FFmpeg/FFprobe，Android 内置音频库。保存/打开使用 Finder、资源管理器和 Android 系统目录选择器/播放器。Android 任务仍在应用进程内，系统结束进程后需要重试。

AV3A 可以保留原始文件并检查完整性，但三端均不能解码或转换成 MP3。杜比编码检查不能证明 Atmos 元数据。登录、会员授权、官方网页结构和音频来源受网易云/GD Studio 实际服务影响。历史会员实测不能替代本次三端同账号验收。
