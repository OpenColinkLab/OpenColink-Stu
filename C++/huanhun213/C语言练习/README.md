# C 语言练习

> OpenColink 学生项目仓库 · 贡献者：huanhun213

C 语言学习过程中按知识点整理的示例程序，共 43 个单文件程序。每个 `.c` 文件都可以独立编译、独立运行，用于验证某个语法点或数据结构的实现。

## 开发环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| 编译器 | MSVC（Visual Studio Build Tools，cl 19.x） |
| 编辑器 | VS Code + C/C++ 扩展 |
| 源文件编码 | UTF-8（无 BOM） |

## 编译与运行

每个 `.c` 文件相互独立，直接在对应目录下编译：

```bat
cl 文件名.c
文件名.exe
```

若编译时出现 `C4819`（代码页 936 无法表示的字符）警告，加上 `/utf-8` 参数即可：

```bat
cl /utf-8 文件名.c
```

`07-文件操作` 中的程序运行时会读写同目录下的数据文件（如 `hello.txt`、`score.txt`），需保证这些文件与生成的 exe 位于同一目录。
