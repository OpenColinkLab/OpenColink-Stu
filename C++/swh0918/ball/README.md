# 三位数各位数字之和（ball.cpp）

## 功能

从键盘读入一个整数并判断它是否为三位数（100 ~ 999）：

- 若是三位数，分别取出百位、十位、个位，求和后输出；
- 若不是三位数（含负数、两位数、四位数及以上），输出提示信息。

## 环境

- 语言：C / C++
- 编译器：支持 C++11 及以上的编译器均可（Dev-C++、g++、MSVC 等）
- 依赖：仅使用标准库 `<stdio.h>`，无第三方库
- 源文件编码：GBK（简体中文 Windows 的 ANSI 编码）

## 接线

本项目是纯软件控制台程序，不涉及任何硬件，**无需接线**。

## 运行方法

### Dev-C++ / Code::Blocks

打开 `ball.cpp`，按 `F11`（编译并运行）。

### 命令行（g++）

```bash
g++ ball.cpp -o ball
./ball
```

### Visual Studio

新建“控制台应用”项目，把 `ball.cpp` 加入项目后按 `Ctrl + F5` 运行。

> 若在网页上直接查看 `ball.cpp` 时中文字符串显示为乱码，是源文件采用 GBK 编码所致；下载后用 Dev-C++ / Visual Studio 打开即可正常显示。

## 运行示例

```text
输入一个三位数：123
三位数的各位和为6
```

```text
输入一个三位数：99
输入的不为三位数
```
