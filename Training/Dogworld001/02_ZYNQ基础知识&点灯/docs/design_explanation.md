# 实现说明

本实验让 PL 端顶层端口 led_red 输出固定逻辑电平，通过 W14 引脚控制 EBAZ4205 的目标 LED。

`assign led_red = 1'b0;` 表示持续输出一位逻辑 0；改为 `1'b1` 后持续输出逻辑 1。两种源码分别重新生成并下载比特流，观察到 0 亮、1 灭，说明该板上目标 LED 低电平有效。

XDC 中 PACKAGE_PIN 把顶层端口绑定到封装引脚 W14，IOSTANDARD 指定 LVCMOS33。源码和约束的端口名称必须一致。

Vivado 流程：建立 RTL 工程 → 添加 Verilog 与 XDC → 确认顶层 → 综合 → 实现 → 生成 bit → JTAG 下载 → 观察 LED。

本设计不需要时钟。时序报告中的时钟/路径统计不应用来说明已验证了某个工作频率。原报告保留 ZPS7-1 警告，表示设计没有实例化 PS7；本次没有修改检查级别或屏蔽该警告。
